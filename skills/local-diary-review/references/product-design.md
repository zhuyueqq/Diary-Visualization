# 本地跨年日记成长回顾：产品设计

状态：规划。现有版本只有基本词频、月份片段统计与日记时间线；下述跨年对比、人工修正和持久化尚未实现。

## 产品目标

用户选择本机的多份 Word，回答三个问题：每一年主要在关注什么；哪些具体经历发生了变化；这些变化由哪些原文支持。不要以词频或积极词数量评价一个人是否成长。

2020—2026 共 7 年。6 份文件可以跨年、同年多份或缺年，文件与年份不能一一绑定。界面文案使用“选择本地文件”，不使用“上传”。

## 使用流程

选择多份 .docx → 检查读取与日期归属 → 查看跨年总览 → 选择两年对比 → 打开经历与原文 → 自己补充回顾。

导入后先展示每份文件的解析状态、识别日期范围、待确认日期、重复候选。失败单独列出，允许其余文件继续。解析在后台执行并显示进度，避免大文件使窗口无响应。

日期：优先明确的日记标题，其次用户确认的文件年份，再使用可解释规则补齐只有月日的标题。跨年文件不能默认补成同一年。保留原始日期、归档日期、依据和用户修正；无法判断的记录进入待确认区。

同一文件用内容哈希识别重复；跨文件重复日记用内容与日期提出候选，由用户确认是否排除。重复原件不删除。没有有效正文时明确提示，不展示看似正常的空报告。

## 页面一：跨年总览

顶部为动态年份选择器、日期范围与资料完整性提示；选择范围允许不限于 2020—2026。

主体为“主题 × 年份”热力图：学习、工作、关系、健康、兴趣、家庭等主题可修改。默认指标为该年涉及主题的日记篇数 / 该年可分析日记篇数；一篇可有多个主题，因此总和不一定等于 100%。点击色块看该年相关日记与分类依据。

每年一张卡：有记录天数、正文字符数、可识别日期比例、主要主题、已确认里程碑数。缺失年份显示“无可用记录”，而不是零分或下滑。

词语采用每万有效词出现次数辅助比较，并同时提供原始次数。低样本标记，不能用一个词的一次出现制造夸张增长百分比。

## 页面二：两年对照

选择任意两年，左右并排展示同一主题。优先横向条形图和差值，不默认使用雷达图或词云。

展示主题占比变化、常提及的新词/持续词/少提及词、两边对应的原文入口。标签写“更常提及”，不要写成“变得更在意”。

非完整年份（例如上半年）默认提醒资料范围不同，支持比较相同月份；归一化不能消除缺失月份带来的偏差。只有年份日期的片段参与年度总览，但不编造月份加入月度比较。

## 页面三：经历时间线

按年/月折叠，支持主题和人物筛选。事件卡包含标题、日记日期、可选事件日期、原文位置、自动候选/已确认标记、个人感悟。

里程碑可以由规则发现候选：第一次、完成、毕业、搬家、开始尝试等。但候选不得自动变成重大事件。用户可编辑或取消，原始引文仍保留。

“困难—行动—结果”默认由用户关联相关日记；自动匹配只能提供候选，不推断结果或编造因果关系。

## 页面四：我的回顾

用户为每年填写“我尝试了什么”“我如何应对困难”“哪些东西依然重要”。保存自己的回顾和收藏片段，支持回到原文。此页面不强迫正面叙事，也允许困惑、失落和未完成的事情。

## 本地架构与存储

第一阶段延续 Python 桌面入口，支持多文件选择、本地解析与静态 HTML 总览。不需要服务器，HTML 依赖全部内嵌或本地打包。报告内容一律作为文本插入 DOM，禁止把日记内容直接当 HTML 执行。

引入持久化编辑时，采用本地桌面界面管理 SQLite，再生成可浏览的静态报告；不把浏览器 localStorage 作为唯一资料库。不为实现编辑就默认启动对局域网开放的服务。

本地项目目录保存数据库、用户修正、主题词典和新建报告。原 Word 仅只读引用，不自动额外复制。输出目录由用户选择，说明报告包含全文；默认提供不含原文的导出选项，但不能把“去掉姓名”宣称为完全匿名。

数据结构：source（本地路径/哈希/读取状态）、entry（稳定 ID/原文段落定位/原始与修正日期/日期精度）、tag（规则版本/证据/确认状态）、milestone（关联 entry/标题/确认状态）、reflection（用户回顾）。词典重算与用户手动修改分开保存。

离线中文分词与可编辑规则足够支撑第一版。可选本地模型在后期单独配置，用于候选摘要；模型文件和运行资源准备好之后完全离线推理。无法满足时保持规则功能，不回退到云端。

## 交付顺序

第一版：多文件选择、导入质量表、日期核对、去重候选、年度归一化主题热力图、两年对比、原文追溯。先解决“每一年有什么不同”。

第二版：本地数据库、永久保存日期和主题修正、确认里程碑、收藏与年度回顾。先保存人工修改，再做复杂推断。

第三版：用户需要时增加本地模型辅助摘要、人物地点关系、跨年困难与行动关联。不得宣称情绪曲线代表心理健康水平。

## 验收场景

- 六份文件跨七年：按实际日期显示年份；未覆盖年份提示缺失，不填充经历。
- 同一年多份文件合并；跨年文件拆分归档；无日期片段可修正，保留原始依据。
- 重复导入不导致确认后的统计翻倍；重算不丢失用户修正。
- 年度字数相差十倍时，同时展示样本量与归一化指标。
- 不完整年份可切换相同月份比较；覆盖差异始终可见。
- 每个自动结论有原文入口；证据不足只显示统计或候选。
- 日记含 HTML/脚本字符不会执行；断网完成导入、分析和浏览；原件哈希保持不变。
- 隐私检查使用合成日记验证无出站请求；真实日记不得输出到聊天日志。
