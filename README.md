# Diary-Visualization

Word 日记回顾

1. 在 VS Code 中打开 diary_insights.py，选择 Python 3.13 后点击运行。
2. 在弹出的窗口中选择日记文件夹。程序会递归读取里面的 .docx 文件。
3. 等待浏览器打开报告。结果保存在脚本旁 reports 文件夹内，每次生成独立目录。

报告包含：高频词条形图、每月记录片段数、可搜索的日记时间线、原文展开。
同时导出词频.csv、时间线.csv、读取情况.json。

命令行用法：
py -3.13 diary_insights.py "D:\日记"

依赖安装（本机已安装则不必重复）：
py -3.13 -m pip install jieba

可选定制：在脚本旁新建 stopwords.txt，每行一个不想统计的词；
新建 user_dict.txt，每行一个人名、地名或专用词，可改善分词。

限制：
- 支持 .docx 正文和表格，不读取扫描图片、页眉页脚、批注；旧版 .doc 请用 Word 另存为 .docx。
- 支持 YYYY-MM-DD、YYYY/MM/DD、YYYY.MM.DD、YYYY年M月D日。
- 仅文件名日期与段首短日期标题用于归档，不推断无年份日期，不使用文件修改日期。
- 一个 Word 可以包含多个带日期标题的日记片段；建议将日期单独放在一段。
- 词频不代表事件的重要程度；目前不自动推断情绪，不自动生成经历总结。
- 报告包含提取的日记全文，分享报告等于分享其中内容。
- 处理期间不上传日记，不删除、修改任何原始日记；仅新建报告文件。
